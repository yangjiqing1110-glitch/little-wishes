# 香香的心愿本 · 写给臭臭

在线地址：<https://yangjiqing1110-glitch.github.io/little-wishes/>

一个只属于香香和臭臭的小网站：把「想让臭臭做的事」「想让你改的小毛病」「想吃的东西」「想要的小礼物」「想说的话」一条条收进来，慢慢实现。

页面里，棕色小熊 **布布 = 臭臭**，白色小熊 **一二 = 香香**。

## 怎么打开

直接双击 `index.html` 就行（Chrome / Edge 都可以），不需要安装任何东西、也不需要联网。

如果想要一个网址，可以在本文件夹里运行：

```powershell
python -m http.server 8137
```

然后打开 <http://127.0.0.1:8137>。

> 换一种打开方式（双击文件 ↔ 本地网址）会看到不同的数据，因为浏览器按来源分开保存。选定一种方式用就好。

## 能做什么

- **五个抽屉**：想让你做 / 想让你改 / 想吃 / 想要 / 想说的话，每类有自己的颜色。
- **新增**：写好内容，选个抽屉，点「收进本子」；也可以按 `/` 直接开始，`Ctrl / Cmd + Enter` 提交。
- **心愿墙**：按分类筛选、只看没实现的、置顶最想先做的那几条。
- **实现啦**：点一下卡片上的 ✓，卡片会盖上「已实现」的章，顶部进度条也会往前走。
- **修改 / 删除**：点卡片文字可以就地改；删除会留几秒「撤销」的机会。
- **抽一条**：不知道从哪件开始的时候，让它随便挑一条。
- **备份**：页脚「导出备份」会下载一个 `.json`；换电脑或清理浏览器前，用「导入备份」就能搬回来。

## 数据存在哪

只存在你这台电脑的浏览器里（localStorage），不会上传到任何地方。清理浏览器数据前记得先导出备份。
